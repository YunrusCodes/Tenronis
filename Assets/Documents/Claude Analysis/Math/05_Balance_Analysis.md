## 1. 理論擊殺時間估算

### 1.1 假設條件

- 玩家每 2 秒消除 1 次（方塊下落 0.8s × 2~3 次操作）
- 每次消除 1~2 行（取平均 1.5 行，R 取 1.5）
- combo 假設穩定在 2~3（有 Counter Lv1+ 時）
- Buff 等級隨關卡進度增長

### 1.2 各成長階段的單次消除傷害

#### 階段 A：起始狀態（Stage 1~2）

```
Lv: salvo=1, burst=1, volley=0, counter=1
假設: R=1, combo=1

DMG = 1 + 0 + 1×1×0.25 = 1.25
導彈 = 1 × 10 × 1 = 10
單次傷害 = 12.5
```

#### 階段 B：初期成長（Stage 3~5，約 3~5 Buff）

```
Lv: salvo=2, burst=2, volley=0, counter=2
假設: R=1.5, combo=2

DMG = 1 + 0.5×2×0.5 + 2×2×0.25 = 1 + 0.5 + 1 = 2.5
導彈 = 1.5 × 10 × 1 = 15
單次傷害 = 37.5
```

#### 階段 C：中期（Stage 6~8，約 8~12 Buff）

```
Lv: salvo=3, burst=3, volley=1, counter=3
假設: R=2, combo=3

DMG = 1 + 1×3×0.5 + 3×3×0.25 = 1 + 1.5 + 2.25 = 4.75
導彈 = 2 × 10 × 2 = 40
單次傷害 = 190
```

#### 階段 D：後期（Stage 9~10，約 15~20 Buff）

```
Lv: salvo=5, burst=5, volley=3, counter=5
假設: R=2, combo=5

DMG = 1 + 1×5×0.5 + 5×5×0.25 = 1 + 2.5 + 6.25 = 9.75
導彈 = 2 × 10 × 4 = 80
單次傷害 = 780
```

## 2. 平衡問題分析

### 2.1 問題 1：後期最終 Boss 擊殺速度過快

**現象**：Stage 10 Boss 在所有主題中估算擊殺時間 < 10秒。

**根本原因**：
```
傷害增長 ≈ O(Lv_burst × combo × Lv_volley × R)
  → 四個變量的乘法效果

HP增長: 線性（60 → 2500，約 42 倍）
傷害增長: 12.5 → 780（約 62 倍）
  → 加上反擊和處決：實際 > 100 倍
```

**嚴重程度**：🟠 中度
> v2.0 舊文檔認為「400倍 vs 42倍」是嚴重失衡，但那是基於 BASE_MISSILE_DAMAGE=2.0。
> 修正為 1.0 後，失衡程度約為 62倍 vs 42倍，仍然存在但不如之前嚴重。

**建議**：
```
方案 A: 提高後期 Boss HP
  Theme_1 Stage 10: 2000 → 3000
  Theme_3 Stage 10: 2500 → 4000
  預期效果: 擊殺時間從 6~8s → 10~15s

方案 B: 對 Burst 加入遞減
  combo > 8 後，每點 combo 的 burst 加成減半
  風險: 改變核心手感，需謹慎測試
```

### 2.2 問題 2：Burst 在高 Combo 時增長過快

**現象**：Burst 是唯一與 combo 線性掛鉤的乘數。

```
combo=10, Lv_burst=6:
  burstBonus = 6 × 10 × 0.25 = 15
  → 基礎傷害 1.0 的 15 倍！

而 salvoBonus 最大只有:
  salvoBonus = 3 × 6 × 0.5 = 9（R=4, Lv=6）
```

**嚴重程度**：🟡 低~中度
> Burst 需要高 combo 才能發揮，而維持高 combo 需要技巧。
> 這本身就是一種平衡機制。

**建議**：
```
方案: 微調 BURST_DAMAGE_MULTIPLIER
  當前: 0.25
  建議: 0.22 (-12%)

  combo=10, Lv=6:
    舊: 6×10×0.25 = 15
    新: 6×10×0.22 = 13.2 (-12%)

  combo=3, Lv=2:
    舊: 2×3×0.25 = 1.5
    新: 2×3×0.22 = 1.32 (-12%)

  影響: 全面-12%，但主要影響高 combo 場景
  風險: 低
```

### 2.3 問題 3：Theme_0 Stage 5 Boss HP 異常

**現象**：Tutorial 主題的 Stage 5 Boss HP = 1000，遠高於 Stage 10 Boss (900)。

```
Stage 5: HP=1000, shootInterval=1.0s（最快）
Stage 6: HP=350
Stage 10: HP=900
```

**嚴重程度**：🟡 低度（可能是設計意圖）
> 可能是故意設計的「教學牆」，讓玩家理解升級系統的重要性。
> 但如果新手在 Stage 5 卡關太久，體驗可能不佳。

**建議**：
```
方案: 降低 Stage 5 HP 或增加獎勵
  當前: HP=1000, reward=1
  建議: HP=700, reward=2
  預期: 擊殺時間從 ~54s → ~38s
```

### 2.4 問題 4：Gravity 主題（Theme_4）沒有直接傷害子彈

**現象**：Theme_4 完全不使用 Normal 和 AreaDamage 子彈。

**影響**：
- 玩家不會因子彈穿透而損失 HP
- 主要威脅是空間壓迫（InsertRow）導致溢出
- 反擊系統幾乎無法觸發（InsertRow 子彈先命中方塊，但方塊立即被移走）
- Counter + Burst 路線在此主題效果大幅降低

**嚴重程度**：🟠 中度（影響遊戲風格多樣性）
> 這不是 bug 而是設計選擇，但可能導致某些 Buff 組合在 Theme_4 中完全無效。

**建議**：
```
保持現狀（如果是設計意圖）
或者：Theme_4 後期加入少量 Normal 子彈（如 Stage 8~10 添加 Normal chance=0.3）
```

## 3. 各主題難度曲線

### 3.1 敵人 DPS 估算

假設子彈命中率為 80%（部分被導彈攔截）：

```
敵人 DPS = (1 / shootInterval) × hitRate × 平均傷害

Normal/Area/AddBlock/AddExpBlock 子彈:
  命中方塊: 1 HP 傷害（對方塊）
  穿透到底: 10 HP（對城堡）

InsertRow/InsertVoidRow:
  命中方塊 + 插入整行（空間壓迫）
  不直接造成 HP 傷害，但推高溢出風險
```

### 3.2 威脅指數估算

定義：`ThreatIndex = HP × (1/shootInterval) × bulletDiversity`

| 關卡 | Theme_0 | Theme_1 | Theme_2 | Theme_3 | Theme_4 |
|------|---------|---------|---------|---------|---------|
| 1 | 0 (無攻擊) | 67 | 78 | 63 | 79 |
| 5 | 1000 | 500 | 480 | 720 | 417 |
| 10 | 900 | 2000 | 1800 | **2500** | 1400 |

→ Theme_3 的最終 Boss 威脅指數最高。

## 4. 經濟平衡分析

### 4.1 CP 經濟

```
CP 收入: 每關開始恢復至全滿
CP 支出:
  溢出: -75 CP
  湮滅: -5 CP
  處決: -5 CP
  修補: -30 CP

假設每關:
  溢出 0~1 次: -0~75 CP
  技能使用 3~5 次: -15~35 CP

  CP需求: 15~110 CP
  CP供給: 100~250 CP（視 ResourceExpansion）
```

**結論**：CP 經濟在預設條件下基本平衡。
ResourceExpansion 只在頻繁使用修補（30CP）或需要溢出保險時有價值。

### 4.2 Buff 經濟

```
單主題可獲: 16~21 個 Buff
全 Buff 滿級需: 32+ 個（不含 Defense）
覆蓋率: 50~65%

→ 玩家必須做出策略選擇
→ 不同路線有明顯的強弱差異
→ 這是 Roguelike 的核心設計
```

**結論**：Buff 經濟設計合理，鼓勵策略選擇。

## 5. 敏感度分析

### 5.1 BURST_DAMAGE_MULTIPLIER 敏感度

```
基準: 0.25, Lv=4, combo=5
burstBonus = 4×5×0.25 = 5.0

±10%:
  0.225: burstBonus = 4.5 (-10%)
  0.275: burstBonus = 5.5 (+10%)

對總 DMG 的影響（假設基礎 DMG=8）:
  0.225: 8-0.5 = 7.5 (-6.25%)
  0.275: 8+0.5 = 8.5 (+6.25%)
```

**敏感度**: 中（佔總 DMG 的 ~60% 在高 combo 時）

### 5.2 SALVO_DAMAGE_MULTIPLIER 敏感度

```
基準: 0.5, Lv=3, R=3
salvoBonus = 2×3×0.5 = 3.0

±10%:
  0.45: salvoBonus = 2.7 (-10%)
  0.55: salvoBonus = 3.3 (+10%)

對總 DMG 的影響（假設基礎 DMG=8）:
  影響 ≈ ±3.75%
```

**敏感度**: 低~中

### 5.3 Boss HP 敏感度

```
Theme_3 Stage 10: HP=2500
後期單次傷害: ~780

±20%:
  HP=2000: 3 次消除（~6s）
  HP=3000: 4 次消除（~8s）
  HP=3500: 5 次消除（~10s）
```

**敏感度**: 低（因為後期傷害太高，HP 變化對體驗影響有限）

→ 要顯著改變後期體驗，HP 需要增加 **50%+**。

## 6. 調整建議匯總

### 高優先級

| # | 建議 | 具體修改 | 預期效果 | 風險 |

| 2 | 提高最終 Boss HP | Theme_1: 2000→3000, Theme_3: 2500→4000 | 擊殺時間延長 50~60% | 中 |

### 中優先級

| # | 建議 | 具體修改 | 預期效果 | 風險 |
